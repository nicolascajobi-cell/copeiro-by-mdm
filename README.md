# COPEIRO 🏆

**by MDM**

Aplicativo mobile-first para organizar campeonatos amadores de **Futebol, Futsal e Fut7**.

> Organize. Jogue. Faça história.

## Direção do produto

O Copeiro nasce para ser mais simples de usar: criação guiada de campeonato, gestão de times e atletas, geração de jogos, resultados, classificação e página pública para jogadores e torcida.

## MVP

- PWA mobile-first
- Conta de organizador
- Criar e editar campeonatos
- Futebol, Futsal e Fut7
- Pontos corridos, mata-mata e grupos + mata-mata
- Times e jogadores
- Jogos e resultados
- Classificação automática
- Artilharia e estatísticas
- Página pública somente leitura
- Organizador e moderadores

## Desenvolvimento local

```bash
npm install
npm run dev
```

Nunca envie arquivos `.env` ou credenciais para o repositório.
